# Analytics (plan; hooks ready)

Track from early stage: website visits/returning users/referrals/story reads
(first-party, privacy-friendly — no sensitive profiling); Telegram member
growth/views/forwards/reactions; X impressions/engagement when accessible; Instagram
reach/shares/saves. Google Search Console integration hooks prepared (clicks,
impressions, CTR, queries, index status, sitemap health) once the domain exists —
do not delay launch for advanced analytics.

**UTM standard:** `utm_source=<platform>&utm_medium=social&utm_campaign=<type>&utm_content=<story-id>`
measuring social → website → Telegram conversion.

# Corrections Policy

Serious corrections are never silently hidden. Every story keeps versioned snapshots
(`story_versions`) recording what changed, why, when, and which platforms carried it.
Corrections propagate: website story updates in place (one master URL), Telegram
messages are edited (remote message id is stored for this), other platforms as they
come online. The public story page shows a corrections/updates section. Status
`CORRECTED` remains visible with the correction history intact.

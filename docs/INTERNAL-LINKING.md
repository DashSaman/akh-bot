# Internal Linking

- No important orphan pages: home → latest → stories; story → related stories (≤3),
  trust pages from footer; category/topic pages linked from home.
- One master URL per event; related coverage links into that URL, not into
  near-duplicate pages (cannibalization guard).
- No mass-generated tag/entity pages: entity/topic pages only where they carry real
  editorial value (threshold enforced by policy, reviewed in admin).

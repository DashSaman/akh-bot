# Product

Automated, evidence-based Persian newsroom. Monitors ONLY admin-approved sources
(Telegram channels, approved X accounts, RSS/Atom, approved sites, official
accounts/statements, selected journalists) in fa/ar/en (architecture extensible to
tr/he/fr/de/ru). Pipeline: COLLECT → NORMALIZE → DEDUPLICATE → GROUP INTO EVENTS →
DETECT SOURCE DEPENDENCY → EXTRACT CLAIMS → VERIFY → WRITE ORIGINAL PERSIAN COPY →
AUDIT FACTS → PLATFORM VERSIONS → PUBLISH → MEASURE → CORRECT.

**Business objective:** a large ACTIVE, trusting audience (Telegram/X/Instagram/
Threads/web) as a reusable media asset. Optimize trust, speed, retention, sharing,
returning audience, website traffic, Telegram membership. NOT follower count; never
fake followers/spam/mass-follow/unsolicited replies/platform violations.
Week-one KPI (target, not guarantee): 1,000 active audience members.
Growth levers may tune timing/format/frequency/CTA/cards — never facts, evidence,
uncertainty, political framing or casualty information.

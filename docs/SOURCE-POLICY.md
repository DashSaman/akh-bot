# Source Policy (public)

Only administrator-approved sources are monitored. States: APPROVED / DISCOVERED /
BLOCKED — DISCOVERED is never trusted until approved. Adding a source stamps an
activation time; its pre-existing archive is stored for context only and is never
auto-published (backfill protection). Reliability scores are internal signals, never
proof of truth. Source types (official institution, news organization, journalist,
local observer, aggregator...) are recorded because independence calculations depend
on them. (Mirror of the public trust page `/page/source-policy`.)
